本文以个人使用场景为主，团队使用差异在相关章节单独说明。

平台功能介绍

AI×ESG工作台是面向个人本地使用的ESG工作平台，将项目任务与个人待办、项目管理、客户管理和知识学习放在一起，并借助AI辅助处理具体工作。

  • 项目任务与个人待办管理：统筹今天要做的事，区分项目交付任务与个人日常安排。
  • 项目管理：围绕目标和交付要求安排阶段、依赖、任务与成果，把项目文档关联到具体工作中，持续推进并复盘。
  • 客户管理：记录客户跟进、下一步行动，并结合相关项目与待办延续工作。
  • 知识学习：理解ESG标准、方法论和议题，通过知识关联、图表解读和来源信息辅助学习与查阅。

AI可以结合你提供的资料，辅助梳理计划、整理材料、检索依据和起草工作内容。具体使用条件和操作方法见下文。

先排一个顺手的工作区

进入“今日工作”，按自己的习惯选择组件、调整位置和大小，再保存布局。经常看当天事项，可以把清单放在主要位置；需要安排一周的工作，可以同时放一个日历。

常用组件包括待办清单、看板、今日时间轴、独立日历和时间专注。还可以按需要使用四象限，从重要性与紧急程度两个角度看任务。组件服务于同一批工作事项，按关注的问题选择即可。

操作帮助：组合组件与保存布局。

一句话把事情记进清单

工作台同时管理两类事项：项目任务带有所属项目、阶段和交付要求；个人待办用于独立于项目的日常事务、学习和个人安排。在今日工作中统筹查看时，仍能区分事项来源，项目交付及资料关联回到所属项目处理。

想到一件事，可以直接在“一句话快速创建待办”中写下来。句子包含明确的开始时间、截止时间或时间区间时，工作台会尝试识别，供你检查和修改。

例如：“明天下午3点前，整理好项目资料。”检查日期和截止时间后，点击“添加”，这件事就进入清单。暂时没有确定时间，也可以先记下事项。

清单帮助你查找和完成事项；看板方便查看不同状态；时间轴和日历帮助你看清安排。进入待办详情，还可以修改名称、时间、分类、紧急程度与重要性。

操作帮助：创建和跟进待办。

为一件事留出专注时间

选好任务，设置专注时长，然后开始。中途可以暂停和继续；结束时，可以只结束本次专注，也可以在确认工作已完成后一起完成任务。

任务分析会汇总已有的完成和投入记录。你可以按时间、项目和分类查看，理解已记录的时间分布。未记录的工作时长不会被自动补算为实际投入。

操作帮助：时间专注与任务分析。

沿着知识路径学习ESG

知识学堂围绕标准、方法论和议题组织内容。进入一条路径后，先看有哪些模块，再选择当前需要的知识点。

以MSCI学习路径为例，可以从方法论总览、评级流程或具体议题进入。阅读中文时，使用页面提供的英文对照、图示和来源信息核对内容；需要进一步理解时，再查看可用的原文或官方原图。

各类资料的内容覆盖、版本及审校进度可能不同，阅读时留意具体页面说明。学堂提供学习辅助，不代替对适用官方原件的核对。

操作帮助：知识学堂。

把常用项目安排做成模板

一类项目经常有相似的阶段和交付要求。你可以描述这类项目，或上传已有进度计划，让AI协助梳理；也可以从空白模板开始，自行安排。

核对阶段、子阶段、工期、前后关系和工作内容后，将它保存为项目类型模板。以后开展同类项目时，可以复用这些基础安排，再按实际项目调整。

AI生成的是供你判断的建议。保存模板后，仍需在具体项目中确定实际日期和任务，不会因为生成建议就自动开始执行项目。

操作帮助：项目类型与阶段模板。

用项目管理的方法推进工作

从项目目标和交付要求出发，先梳理阶段、子阶段、前后依赖、输入资料和预期成果，再把阶段工作落实为具体任务与日期安排。执行时结合计划和实际情况，判断哪些工作可以开始、哪些前置条件尚未满足、哪些成果还需要补齐。

例如，一个ESG报告项目可以围绕资料收集、分析、初稿和复核组织工作：每个阶段需要哪些输入、准备形成什么成果、由哪些任务落实，都在同一个项目中衔接。推进过程中，再根据实际情况调整本项目的安排。

项目空间提供“项目推进”“任务”“资料与成果”“项目记录”四个入口。

  • 项目推进：核对阶段及前置关系、计划与实际日期，查看输入要求、预期成果和需要关注的事项。
  • 任务：将阶段工作落实为具体事项，记录所属阶段与截止时间，跟进执行并关联成果。
  • 资料与成果：集中管理项目文档，关联所属阶段或任务，从正在处理的工作找到相关材料与成果。
  • 项目记录：保留执行活动和复盘，回看目标、成果、遇到的问题及下次的改进方向。

具体项目可以调整自己的阶段安排，不必为一个项目的变化改掉通用模板。阶段完成、任务完成和项目结束是不同操作，分别确认。

操作帮助：项目管理与推进。

让AI围绕具体工作提供协助

使用AI时，可以说明工作问题，提供可用资料，或选择当前可用的技能、专家智能体和工作流。适合从有明确输入和结果的事情开始，例如整理一份计划的阶段建议、根据资料回答问题，或协助创建任务。

AI提出建议、返回草稿和实际完成操作是不同结果。涉及任务、计划或资料的变化，要核对实际保存结果；专业结论需要回看来源。

具体能力取决于当前启用的功能、权限和服务状态。不要仅凭一个入口或AI的一句回复判断工作已经完成。

操作帮助：使用AI协助工作。

管理客户与后续跟进

客户管理帮助你记录客户跟进事项，查看后续动作与相关项目、待办。把一次联系要解决的问题、下一步需要推进的事和后续进展持续记录下来，减少客户沟通与项目执行之间的信息断点。

操作帮助：客户跟进。

围绕当前工作查找资料

知识库帮助你搜索和查看当前账号可访问的工作资料，并在需要时用于知识问答。知识学堂按学习路径组织知识；知识库更适合围绕当前工作找材料。

操作帮助：知识库查询。

快速开始

这篇帮助你在已有可用账号、能够进入工作台的情况下，完成第一条待办并找到学习和项目入口。

还未安装或登录？先阅读安装与首次使用。

先完成一条自己的待办

  1. 进入“今日工作”。
  2. 在“一句话快速创建待办”中输入“整理本周学习笔记”。第一次可以先不写时间。
  3. 点击“添加”。
  4. 在待办清单中找到这条事项；如果当前筛选中没有出现，切换到“全部”并查看待安排分组。
  5. 点击这条待办，设置开始时间或截止时间，保存。
  6. 完成实际工作后，勾选完成；需要检查信息时重新打开待办。

完成这组操作后，你应当能在清单中找到自己的事项，并确认保存的时间和完成状态。详细操作见待办管理与工作区。

把常用组件放到首页

  1. 点击“＋ 组件”，加入一个“日历”。
  2. 调整组件的位置和大小。
  3. 点击“保存布局”。
  4. 切换页面再回来，确认仍是刚保存的组合。

日历可以作为独立组件与清单并排使用。查看布局帮助。

打开一条知识路径

  1. 从左侧进入“知识学堂”。
  2. 找到想学习的标准或方法论，进入学习路径。
  3. 先查看模块，再打开一个知识点。
  4. 阅读时留意来源、版本与翻译说明。

你可以随时回到路径选择其他内容，不需要按目录顺序一次读完。查看知识学堂帮助。

需要做项目时

先区分两个概念：项目类型模板是可复用的一类项目安排；具体项目计划是本次项目的实际日期和阶段安排。

如果已有适用模板，可以进入项目管理创建项目，再为它排计划；如果没有，先准备一个模板。详细帮助：项目类型与阶段模板 → 项目管理与推进。

选择界面主题

打开账号菜单中的“设置”，进入“个人偏好”，在“主题”中选择清新绿、商务蓝或深色模式。选择后可预览，点击“保存设置”保留偏好。

平台页面、弹窗和抽屉使用统一主题。知识学堂与社区采用各自的页面风格；图表系列和任务分类保留用于区分内容的颜色。

待办管理与工作区

从“今日工作”进入。本文主要针对个人待办；来自项目的任务会显示项目来源，交付信息需要进入所属项目处理。

按习惯组合组件并保存布局

  1. 点击页面右上方“＋ 组件”。
  2. 选择需要的组件；已添加的组件按界面状态处理。
  3. 在布局编辑状态下调整组件的位置和大小。需要修改已有组合时，点击“编辑布局”。
  4. 检查主要信息是否方便查看，再点击“保存布局”。
  5. 出现“布局已保存”提示后，退出并重新进入页面检查结果。

不想保留本轮布局变化时，选择“取消”。“恢复默认”会将编辑中的布局恢复为默认组合；确认满意后再保存。

建议先用“待办清单＋日历”，需要集中工作时再加入“时间专注”。也可以加入“看板”“今日时间轴”或“四象限”。

用一句话创建待办

  1. 在顶部“一句话快速创建待办”中输入要做的事。
  2. 如果写了时间，检查输入区旁识别出的日期与时刻。
  3. 时间不合适时，点击时间文字或“设置起止时间”入口修正。
  4. 按需要选择紧急程度和分类。这些信息可以以后再补。
  5. 点击“添加”。
  6. 在清单中检查事项名称和时间。创建成功后即可开始跟进。

可以从这些例子开始：

输入示例 你希望表达的安排
整理本周学习笔记 先记下事情，暂不安排时间
明天下午3点阅读方法论 指定开始时间
明天下午3点前整理好资料 指定截止时间
今天14:00到15:00阅读方法论 安排一个起止时段

自然语言可能有歧义，保存前以识别出的字段为准。工作台不会因为只写了一个开始时刻，就自动知道这件事需要做多久。遇到同日同名的重复提示时，先检查是否已存在，再决定是否继续创建。

修改名称、时间、重要性与分类

  1. 点击清单中的个人待办，打开“编辑待办”。
  2. 修改任务名称。
  3. 按需要填写“开始时间”和“截止时间”，日期与时刻分别检查。
  4. 选择紧急程度、重要性、分类和状态。
  5. 点击“保存”，回到清单检查变化。

紧急程度表示时间上的紧迫，重要性表示这件事的价值和影响，两者可以分别设置。分类由你自己建立，用来组织和回看工作。

只有截止时间的事项，表示最晚需要完成的时间；一个起止时间区间，表示为工作预留的时段。两者用途不同。

在清单中查看和完成事项

  1. 选择“全部”“今天”或“最近7天”等当前页面提供的范围。
  2. 展开相应分组，找到要处理的事项。
  3. 点击事项查看信息，或在实际完成后勾选完成。
  4. 需要回看时查看“已完成”分组；未显示时先检查当前筛选范围。

未安排日期的待办仍可保存在清单里。清单没有显示某件事时，先查筛选和分组，不必立即重新创建。

用看板查看状态

  1. 加入“看板”组件并保存布局。
  2. 查看不同状态下的事项。
  3. 打开任务修改状态；当前界面支持的拖动操作也可以用于调整。
  4. 修改后检查事项是否出现在对应状态中。

看板中的事项与清单中的事项是同一条任务。正在专注的任务若要改回未开始，先结束这次专注，再处理状态。

四象限用于从重要性和紧急程度看任务；它与按完成状态组织的看板用途不同。

在今日时间轴中查看安排

  1. 加入“今日时间轴”并保存布局。
  2. 查看当天安排在各时刻或时段的事项。
  3. 点击事项核对详情，检查工作是否重叠、是否留出了需要的时间。

时间轴适合查看当天的安排。未写起止时刻的任务，不应被理解为已经占用了某个确定时段。安排变化后，回到任务详情确认保存结果。

使用独立日历组件

  1. 点击“＋ 组件”，选择“日历”，保存布局。
  2. 在日历顶部选择“日”“周”或“月”。
  3. 使用日期切换按钮查看其他时间，或点击“今天”回到当前日期。
  4. 点击事项查看详情；月视图可以通过日期查看该日事项。

月视图适合看分布，周视图适合安排一周，日视图适合查看具体时段。日历与清单可以同时保留，不需要先把清单切换成日历。

只有开始日期的个人待办，按开始日展示；没有完成并不表示它自动占用后续每一天。要把它安排到新的日期，请修改任务时间。

给项目任务安排今日投入

从“今日工作”打开项目待办后，可以查看所属项目和交付截止，按当前入口填写今日开始、结束时间，选择“保存今日投入”。

今日投入表示今天计划用哪段时间处理它，不等于修改项目交付截止。要调整项目任务本身或补充成果，请选择“进入项目空间”。

相关帮助：时间专注与任务分析 · 项目管理与推进 · 常见问题。

时间专注与任务分析

时间专注用于集中处理当前任务，任务分析用于回看已经保存的完成与投入记录。

开始、暂停和结束时间专注

  1. 在“今日工作”加入“时间专注”组件，保存布局。
  2. 将要处理的待办拖入专注区域，确认显示的是这件事。
  3. 通过时间控件设置本次专注时长，点击“开始”。
  4. 需要中断时点击“暂停”，回来后点击“继续”。
  5. 结束时点击“结束”，在确认窗口选择下一步。
选择 适用情况
仅结束专注 这一段工作结束，但整件事还没做完
结束并完成任务 个人待办已完成，可以同时更新任务状态
结束并提交验收 团队项目任务需要按项目流程提交成果时，以实际按钮提示为准

个人项目与团队项目的完成方式可能不同，按当前任务来源及弹窗说明处理。结束专注本身不应被理解为阶段或项目已经完成。

计时中或暂停时要将任务改回未开始，应先结束专注。暂停期间不计为投入时间；专注记录可以在任务的实际执行记录中回看。

查看任务分析

  1. 在“今日工作”右上方点击“任务分析”。
  2. 选择“今天”“本周”“本月”或“自定义”。自定义时填写起止日期并应用。
  3. 根据需要按个人待办/项目任务、项目或分类筛选。
  4. 查看完成/交付、已记录投入、当前逾期未完成、计划与实际、投入分布。
  5. 点击分类统计或查看任务明细，核对具体事项。

以下几个数字含义不同：

  • 期间完成/交付：在所选期间发生的完成或交付记录；项目任务按页面说明的提交口径统计。
  • 当前逾期未完成：截至查看时仍未完成的逾期任务，包含之前遗留的事项。
  • 已记录投入：已有计时记录的投入，不代表全部实际工作时间。
  • 无法判定：历史数据缺少必要依据，例如完成时的截止快照，不能据此判为提前或逾期。

没有计时的工作，不会自动推算真实耗时。分类分布也应结合记录覆盖情况理解。

建立分类并归类任务

可以在快速创建或编辑待办时打开分类入口，创建自己的类别，再选给任务使用。分类初始可以为空，不必先设计完整分类体系。

在任务分析的明细中，先勾选需要处理的任务，再点击“分类”，可进行批量归类。对项目任务设置个人分析分类，不等于改变项目阶段或交付要求。

使用AI分析与历史报告

先检查当前统计范围，再点击“AI分析”。查看返回的观察、建议和数据局限，结合明细判断是否符合实际。

AI建议不会补齐未记录的投入，也不代替你对工作质量的判断。没有可用AI服务时，基础统计和AI解读是不同能力；调用失败不表示任务记录丢失。

通过“历史报告”查看已保存报告。历史报告反映生成时的数据，与当前实时统计可能不同。

按需要开启定时报告

  1. 点击“定时报告”。
  2. 选择是否启用、每日/每周/每月、执行时间，以及是否包含AI分析。
  3. 阅读页面对报告期间和运行条件的说明，保存设置。
  4. 以后从历史报告中查看结果。

当前报告在本机服务运行时生成；停止期间不会执行，恢复后只补最近一期。当前没有配置对外推送渠道，报告保存在平台中。“定时报告”不等于已经向其他应用发送通知。

知识学堂

知识学堂帮助你从一个标准或方法论的全貌，逐步进入具体议题。当前不同标准采用的页面形式可能不同，本篇说明共同的使用方式。

找到一条学习路径

  1. 从左侧导航进入“知识学堂”。
  2. 浏览当前可用的路径，或按页面提供的分类、标签缩小范围。
  3. 查看路径介绍，确定它与你要了解的问题有关。
  4. 点击路径卡片或“进入学习”。

以MSCI为例，可以先了解方法论总览和评级流程，再进入行业或具体议题。已经知道要查什么，也可以直接进入对应议题。

打开知识点并阅读

  1. 在路径内找到相应模块或议题。
  2. 点击知识点卡片或页面提供的进入按钮。
  3. 先看标题和适用范围，再阅读正文、表格和图示。
  4. 使用页内目录定位章节；需要换内容时，通过页面的返回或路径入口回到上一级。

页面若提供学习状态操作，可标记学习中或已学完。并非每种定制阅读页都有同一组状态按钮；没有对应入口时，不把打开或停留等同于已完成学习。

阅读中文并核对英文

在提供中英文配对的内容处，将鼠标停留在对应中文上查看英文。需要逐项核对时，按段落、表格条目或图示文字分别查看。

阅读时注意页面采用的来源：官方中英文都有时，以官方中文呈现并对应官方英文；只有中文时直接阅读中文；只有英文且已完成对应处理时，中文为AI翻译，并保留英文及翻译说明。

英文对照的可用情况请查看具体知识点。遇到没有英文对照、译文不清楚或配对可疑的内容，先检查来源和页面说明，再反馈具体知识点。

查看表格、图示和原件

  1. 先结合正文阅读图表的标题、单位、注释和来源。
  2. 如果提供官方原图或展开入口，打开后核对原件。
  3. 如果只有文字解读或中文图解，不将其当作官方原件的完整替代。
  4. 需要引用某项具体规则或数字时，回到对应原件核对版本和适用条件。

图表的可查看方式随内容而异，只有提供相应入口的页面才能展开原图。

查看来源、版本与翻译说明

在知识点正文、页面下方或资料来源区域查看：发布机构、文件名称、版本/日期以及采用说明。来源信息用于判断你读到的是哪份资料，不应只根据页面更新时间认定它就是最新官方版本。

反馈内容问题时，尽量提供路径名称、知识点标题、具体段落或图表位置，以及你发现的问题。这样更容易定位和复核。

知识学堂与知识库的区别

知识学堂适合按路径学习；知识库适合围绕当前工作查资料。一个议题在学堂中讲如何理解，在知识库中则可能对应多份可查阅的工作材料。

相关帮助：知识库查询 · 常见问题。

项目类型与阶段模板

项目类型模板保存一类项目的阶段、工期、关系和工作内容，供新建同类项目时复用。它不等于某个项目已经开始执行。

选择配置方式

从设置中的“项目类型与阶段”进入。个人模式以及有相应权限的账号可管理模板，其他账号以实际可见入口为准。

已配置的项目类型显示为卡片。查看或修改已有类型时，打开相应卡片；新建时有两种方式：

  • AI辅助配置：描述项目，或上传已有计划，由AI建议阶段和安排。
  • 个人自定义配置：从空白模板开始，自己添加阶段与工作内容。

用AI辅助梳理阶段

  1. 选择“AI辅助配置”。
  2. 描述这类项目要完成什么、有哪些已知阶段、需要哪些成果。有已有计划时，可以一并上传。
  3. 查看AI对需求的理解；存在偏差时，先补充或纠正。
  4. 查看详细建议，逐项核对阶段、子阶段、顺序/并行关系、工期和工作内容。
  5. 修改不合适的安排，尤其检查AI提出的假设。
  6. 核对阶段表和甘特排期，再确认保存模板。

示例描述：为一类ESG报告编制项目梳理阶段，包含启动、资料收集、分析、报告编制和审核；请分别列出主要工作、输入资料、预期成果与建议工期。

上传原有计划时，旧项目日期可能只是参考。制作通用模板时，先核对阶段关系和相对安排；新项目的实际日期留到创建具体计划时确定。

手动配置或调整模板

  1. 选择“个人自定义配置”，或打开已有类型卡片。
  2. 填写类型名称和适用场景。
  3. 添加阶段；复杂工作可以继续拆成子阶段。
  4. 逐项填写工作内容、输入、输出和工期，并检查前后关系。
  5. 查看排期预览，确认并行工作、汇合点和整体工期是否合理。
  6. 保存后回到类型列表，确认卡片和内容已经更新。

工期采用自然日还是工作日，以当前编辑页的工期单位为准。父阶段与子阶段不是两份重复工作，不要把汇总阶段的工期再加到子阶段工期上。

在具体项目中使用模板

创建项目时选择相应类型，再在该项目内核对阶段并生成实际进度计划。项目保留创建时的阶段安排；后来修改通用模板，不会直接覆盖已有项目的任务、资料和阶段。

只想调整当前项目时，使用项目内的“编辑本项目阶段”，无需先修改基础模板。

生成或保存模板不会自动创建全部项目任务。进入具体项目后，再按阶段创建和核对任务。

常见问题

AI理解错了，能直接保存吗？

先修改需求或调整方案，再保存。建议缺少资料或出现假设时，结合自己的项目判断，不能把建议当成原资料已有的事实。

删除模板会不会删除已有项目？

当前类型删除提示说明已有项目及阶段安排保留；新建项目将无法再选择该类型。操作前仍应核对删除对象与页面提示。

下一步：项目管理与推进。

项目管理与推进

项目空间帮助你用项目管理的方法组织一次具体工作：围绕目标与交付要求梳理阶段、依赖、输入资料和预期成果，再落实到计划、任务与执行记录。项目文档可以关联到阶段和任务；需要时，借助AI辅助整理资料、梳理计划和准备工作内容。本文以个人项目为主，团队项目的分工与验收另按权限处理。

创建项目并安排计划

  1. 从左侧进入“项目管理”，选择“新建项目”。
  2. 按表单填写项目名称、适用类型以及必要的信息，确认创建。
  3. 打开项目。在尚未保存计划时，页面会先显示“为项目制定计划”。
  4. 点击“创建项目计划”，核对本项目的阶段；需要时调整阶段和子阶段。
  5. 选择“下一步：生成项目计划”，进入日期安排。
  6. 设置实际开始日期，核对工期单位与阶段安排，按界面提供的方式生成或调整。
  7. 点击“保存计划”。回到“项目推进”，检查阶段日期和计划保存状态。

阶段模板提供基础结构，具体项目计划需要你核对日期。生成预览不等于已经保存。

调整计划或本项目阶段

已保存计划后，打开项目右上方“更多”：

  • 调整日期：选择“调整项目计划”；阶段变化后可能显示“核对项目计划”。
  • 调整结构：选择“编辑本项目阶段”，修改阶段、子阶段、工期或工作内容。

阶段保存后，按照页面提示重新核对计划并保存。只改当前项目的阶段，不会直接改掉通用模板。保存结构变化也不代表全部关联任务的截止时间已自动改好，需要继续检查任务。

阅读项目推进页面

可以在“甘特图”和“阶段表”之间选择。

甘特图帮助你看阶段跨度和并行关系；阶段表更适合逐行核对计划开始、计划结束、实际开始、实际完成与状态。计划日期表示预期安排，实际日期来自执行记录。

点击阶段，查看主要工作、前置阶段、输入要求、预期成果、关联任务与资料。阶段如果显示等待前置完成，先确认依赖是否真的满足；确需提前开展时，阅读并确认页面提示。

开始和完成阶段

在阶段入口或详情中，按当前状态选择开始阶段或完成阶段，并核对确认提示。

阶段完成和任务完成分别记录。仍有未完成任务时，完成阶段不会自动把它们改为已完成。先检查成果和未完成事项，再作确认。

创建和跟进具体任务

  1. 在项目中选择“创建任务”，或从某个阶段详情选择“新增任务”。
  2. 填写任务名称，确认所属阶段、交付截止和必要工作信息。
  3. 保存后进入“任务”页，找到刚创建的任务。
  4. 打开任务详情，开始工作；需要时关联成果。
  5. 工作完成后，按个人或团队方式处理完成状态。

个人项目可以由本人确认“完成任务”。团队项目成员通常提交成果，项目经理按权限验收；提交成果与验收完成不是同一个状态。

任务页可以按状态和逾期情况筛选，也可以搜索任务名称。找不到事项时先检查筛选、项目和所属阶段。

保存与查找资料和成果

  1. 在项目中点击“上传资料”，或从阶段/任务入口关联资料与成果。
  2. 选择文件，检查它的用途与关联阶段、任务信息。
  3. 完成保存后，进入“资料与成果”核对文件名称和归属。
  4. 从文件列表或关联的阶段、任务中查看文件。

项目资料应留在所属项目。上传资料、形成草稿和确认最终成果是不同动作；不要仅凭文件存在判断交付已经完成。

回看记录、复盘和结束项目

进入“项目记录”回看活动。需要写复盘时，从“更多”选择“项目复盘”，填写目标、成果、遇到的问题及下次可以改进的地方，保存。

当前项目复盘笔记保存在本项目，保存笔记本身不调用AI。

个人项目确认结束后会变为只读，保留任务、资料和投入记录；未完成任务不会自动标为完成。因此，结束前应先核对遗留事项和成果。团队项目按项目经理确认的结束复盘与归档流程处理。

相关帮助：项目类型与阶段模板 · 待办管理与工作区。

AI、知识库与客户跟进

你可以向AI说明具体工作，在知识库中查找资料，也可以记录客户跟进事项。本章介绍这三个入口的基本用法。

向AI说明一件具体工作

  1. 从当前页面的AI助手入口打开对话。
  2. 说明要解决的问题、使用的资料范围，以及你希望得到的结果。
  3. 当前入口支持引用知识或项目文件时，选择相关材料。
  4. 如果AI需要补充资料或确认，先核对内容再继续。
  5. 查看结果并检查来源；涉及任务或文件操作时，回到对应页面核对实际保存情况。

描述可以具体到：“请根据我提供的阶段安排，指出哪些工作可以并行，先给建议，不修改项目计划。”

另一类需求是：“请帮我创建明天下午整理项目资料的待办。”这类请求需要当前AI能力支持任务操作；核对候选和时间后，检查清单中是否确实生成任务。仅收到文字建议时，任务还不一定已经创建。

配置文字与图片默认模型

在提供“获取模型列表”按钮的版本中，可以分别选择文字和图片的默认模型：

  1. 打开“设置—个人偏好”，找到“个人文字模型 API”或“个人图片 API”；有“API 使用方式”选项时，选择使用个人 API。
  2. 填写上游服务提供的 API 基础地址和 API Key。地址未改变且密钥已保存时，Key 可以留空。
  3. 点击“获取模型列表”，在“默认文字模型”或“默认图片模型”中选择需要的模型。
  4. 点击“保存个人设置”。重新打开设置，检查默认模型是否保留。

获取列表不会自动修改默认模型或保存配置。文字与图片分别设置；图片列表由上游提供，请选择该服务支持图片生成的模型。

尚未获取列表、没有返回模型或服务不支持模型列表时，直接在输入框填写上游提供的准确名称后保存；只有获取到可选模型后，才显示下拉列表。更换 API 地址后，需要重新填写对应密钥再获取列表；获取失败时，原默认模型仍会保留。列表获取成功不代表该模型已开通调用权限，实际使用仍取决于上游服务的授权和余额。

使用技能、专家智能体与工作流

在“AI专家助手”中，可以查看当前提供的技能、专家智能体和工作流。先阅读用途、输入要求及可用状态，再选择适合当前工作的入口。

在支持快捷调用的对话中，可按界面提示使用“/”选择已启用的技能，使用“@”引用可访问资料。各技能能做什么，以当前说明与实测结果为准。

出现失败、缺少资料或待确认提示时，先按提示处理。不要仅凭回答中的“已完成”认定任务、文件或项目已发生变化。

在知识库中找资料

  1. 从左侧进入“知识库”。
  2. 在搜索框中输入标题、路径或分类关键词。
  3. 结合分类筛选，找到相关资料。
  4. 打开条目查看当前支持的内容或原始来源。
  5. 需要结合资料提问时，使用“使用知识问答”入口，并说明要核对的问题。

当前页面可能包含本地资料与已接入来源的只读资料。能搜索到什么取决于当前账号权限和可用索引；搜索结果不能代表全部外部资料都已接入。

看到没有结果或索引未就绪时，先清除筛选、换一个明确关键词，并查看页面提示。

记录客户跟进

  1. 从左侧进入“客户管理”；个人模式可能显示“我的客户”。
  2. 点击“新建跟进”，按表单填写客户与跟进事项。
  3. 写清楚下一步要做什么，核对时间后保存。
  4. 回到列表，通过客户名称或跟进事项查找记录。
  5. 按实际进展更新跟进，查看关联项目与待办。

当前客户列表可由关联项目和跟进事项汇总。修改一条跟进不等于已经对外发送消息；需要联系客户时，仍应通过你实际使用的沟通方式完成。

常见问题

一句话创建的时间不对，怎么办？

先检查识别出的日期和时刻，再通过时间文字或设置起止时间入口修改。开始、截止和时间区间要分别理解。已经创建时，打开待办修改并保存。

没写时间的待办去了哪里？

进入清单，切换到“全部”，检查待安排分组。先不要重复创建。

修改日历里的事项，会不会另建一条任务？

日历、清单等组件用于查看同一条任务。编辑和新建是不同操作，保存后核对事项名称及时间即可。只有主动新建或确认重复创建时，才应产生另一条任务。

结束专注后，任务为什么还没完成？

“仅结束专注”只结束这一段投入。确认整个任务已做完时，再选择完成任务。团队项目可能还要经过提交和验收。

分析页的时间为什么比我实际工作时间少？

页面汇总的是已记录投入。没有计时的工作和暂停期间不能被当作已记录工作时长。历史数据不完整时，应结合明细和页面说明判断。

只修改了今天的投入，项目截止为什么没变？

今日投入是今天安排做这件事的时段，交付截止是项目任务要求完成的时间。要改交付截止，进入所属项目并按权限处理。

保存了项目模板，为什么项目里没有所有任务？

模板用于保存阶段安排。创建具体项目、保存实际日期计划、创建具体任务是后续不同操作，生成模板不等于已执行这些操作。

修改模板，会不会覆盖已有项目？

已有项目保留创建时的阶段安排。要调整某个项目，进入该项目修改阶段和计划，并核对关联任务。

任务都完成了，阶段为什么还需要确认？

任务完成只是阶段验收的依据之一。阶段还可能需要检查整体成果，完成确认单独处理。

知识点里没有英文对照，是不是出错了？

先看原始资料是否有英文，以及该知识点的翻译和来源说明。官方仅中文的内容不提供英文对照；有英文原文却未显示对照时，可反馈路径、标题和具体位置。

AI说已经完成，我还要检查什么？

检查实际任务、文件或计划是否已保存，以及结果是否符合输入要求。AI建议、草稿和实际执行结果应分别判断。

新版本为什么没有我看到的某个功能？

不同版本的功能和知识内容可能有所差异，请以当前使用的版本为准。反馈时说明版本和所在页面，便于定位问题。

安装与首次使用

从安装工作台到进入首页，按下面的顺序完成即可。本文的安装步骤适用于收到 Windows 安装包的用户；支持的系统版本和电脑配置，请查看随包提供的版本说明。

获取适合你电脑的安装包

从平台提供的下载入口或交付渠道获取安装包，同时保留版本说明和账号使用说明。

  • 安装版：文件名含 Setup，用于在电脑上安装工作台。
  • 便携版：文件名含 Portable，仅在该版本提供时使用，按随包说明运行。
  • 不要把源码压缩包当作安装包。Windows 的 .exe 文件不能直接在 macOS 上安装。

如果没有与你的电脑匹配的安装包，请先联系提供方确认。已有旧版的用户，先阅读本章的“更新与数据保留”。

在 Windows 上安装

  1. 找到下载完成、文件名含 Setup 的 .exe 安装文件，双击打开。
  2. 按安装向导选择安装位置，继续完成安装。
  3. 安装完成后，从桌面或开始菜单打开“AI×ESG工作台”。
  4. 等待工作台启动。首次进入时，如果出现“初始化工作台”，继续完成下面的设置。

如果系统拦截安装，先核对文件来源、版本和提示内容，再联系提供方处理。不要通过关闭系统安全保护来解决安装问题。

首次打开：选择工作方式与资料位置

个人使用时：

  1. 在“使用模式”中选择“个人模式”。
  2. 在“本机个人数据目录”旁点击“选择”，指定一个便于查找、能够正常保存文件的文件夹。
  3. 点击“保存配置并进入工作台”。
  4. 等待进入账号页面。

这里选择的是本机资料保存位置，不是软件的安装位置。建议使用固定文件夹，避免选下载临时目录或随时可能断开的移动设备。

如果加入已有团队，选择“团队模式”，再选择团队提供的共享目录，或按团队说明使用“导入团队接入文件”。需要先具备共享目录的访问权限；接入文件不能替代权限申请。团队账号和资料位置请向团队负责人确认。

登录账号

如果收到的是配有账号的安装包，使用单独提供的账号和初始密码，点击“进入工作台”。报名登记与工作台登录是两件事，不能直接把报名信息作为登录账号。

如果你使用的版本在首次打开时显示“创建你的账号”，按页面填写姓名、账号与密码，并再次确认密码，然后点击“创建账号并进入工作台”。密码至少10位，且包含大写字母、小写字母、数字、特殊字符中的至少三类。

已有账号时直接登录，不需要重复创建。账号页面与随包说明不一致，或收到的账号无法登录时，请联系提供方核对，不要通过清空已有资料重新初始化。

使用初始密码登录后，可在设置中的“账号安全”填写当前密码、新密码及确认密码，点击“修改登录密码”。后续使用新密码登录。

确认可以开始使用

进入首页后，可以先做一个简单检查：

  1. 打开“今日工作”，创建一条“体验工作台”的待办。
  2. 确认它已出现在清单中。
  3. 正常退出工作台，再次打开并登录，确认刚才的事项仍然保留。
  4. 阅读快速开始，继续安排工作区和查看知识学堂。

需要使用AI时，留意对应入口的可用状态。安装完成并不代表所有AI服务已连接；若提示服务不可用，按该入口说明处理。

更新与数据保留

更新前先阅读新版本附带的更新及备份说明，备份需要保留的数据，再退出工作台并按说明安装。

软件安装位置与个人资料目录用途不同。仅复制安装文件或某一个资料文件夹，不能视为完成了全部账号、待办、项目与附件的备份。迁移电脑、重装或卸载前，请按对应版本的完整备份说明操作；不明确时，先联系提供方确认。

更新后，重新打开并检查原有待办、项目及附件。卸载软件不等于完成资料备份，也不要在确认数据保留前手动删除相关文件夹。
