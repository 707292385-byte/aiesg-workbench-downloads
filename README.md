## 参与方式

1. 阅读[项目介绍与公测说明](https://my.feishu.cn/docx/DAtKd4CY3of6HrxvnZ8cp9FTn6c)。
2. 开放后填写[公测登记](https://my.feishu.cn/share/base/shrcnzXsEayUoOPSPFY525tMu3f)，称呼可使用代号，邮箱及回访意愿选填。
3. 从下方版本页面的 **Assets** 选择与你的电脑系统、芯片匹配的安装包。
4. 按[首次体验步骤](QUICKSTART.md)使用虚构项目完成测试，再提交反馈。

## 下载与版本

[进入 Releases 版本页面](https://github.com/707292385-byte/aiesg-workbench-downloads/releases)

目前还没有发布版本。出现版本后，请先阅读版本说明及已知问题，再下载安装包；`Source code (zip)` 和 `Source code (tar.gz)` 不是桌面安装包。

测试版本会标记为 **Pre-release**。请以 Releases 列表中的明确版本为准，不依赖 `/releases/latest` 自动选择测试版本。更新前先按对应版本说明备份数据。
